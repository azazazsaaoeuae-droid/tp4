capitre 1: Vue d'ensemble d'un micro-ordinateur

john Von Neumann est a l'origine d'un modéle de machine pour le traitement automatique de l'information.L'architecture proposée est composée de:

  • l'unite de traitement
  • la memoire centrale
  • les unite d'E/S
  • les bus

l'unite de traitement

elle est formée de l'unité de commande ET DE l'unité arithmetique et logique

la memoire centrale

c'est une memoire volatile

les unités d'entrée /sorties

les interfaces d'entrée/sortie permettent l'échange d'informations entre l'unité centrale et les unités périphérique

les bus

c'est un ensemble de fils conducteurs paralles servant transfert des informations entre les composants d'un systéme d'informatique
